APIMatic generates SDKs for your API in **C#**, **Python**, and **TypeScript**. Each SDK comes with utility classes, authentication helpers, configuration files, and strict language bindings, so developers work with your API through native objects and functions.

## Built-in features

Every APIMatic SDK includes:

- Immutable clients
- Timeouts, with automatic retries on API errors
- Access to the HTTP response
- Logging of API lifecycle events
- XML support for sending and receiving data
- Cancellable asynchronous calls
- Multipart requests
