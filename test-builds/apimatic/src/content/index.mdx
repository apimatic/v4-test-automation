# Introduction (/)

APIMatic helps you deliver a great developer experience for your API. Generate well-documented **APIMatic SDKs** and **APIMatic Context Plugins** that give AI coding agents accurate context about them, spin up APIMatic API documentation portals, lint your API definitions, and transform them into other formats with the APIMatic API Transformer.

## Context Plugins [#context-plugins]

AI agents are good at writing code, but they often get API integrations wrong: they call endpoints that don't exist, use the wrong SDK version, or mishandle auth. The problem is context, not code generation.

APIMatic Context Plugins fix that by giving agents version-aware access to your full API reference, your SDKs, code samples, and workflows, right inside the developer's IDE. Generate one with the APIMatic CLI (`apimatic plugin generate`) after publishing your SDKs.
